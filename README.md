# 한국 및 미국 시장 종목별 PER 변화 추이 비교 대시보드 (37 PERcomparison)

한국(KRX) 및 미국(US) 주요 개별 주식 5종목의 과거 PER(Price-to-Earnings Ratio) 시계열 데이터를 확보하고, 지정한 기간(1M, 3M, 6M, 1Y, 3Y) 동안의 밸류에이션 추이를 비교 분석하는 대시보드 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **왼쪽 사이드바 제어 패널**:
   - **5개 종목 선택 (`31 PerformanceChart` 방식)**:
     - 한국 상장 전 종목(KOSPI / KOSDAQ) 및 주요 미국 대형 기술주 검색 및 선택 지원
     - `[직접 입력]`을 통해 원하는 전 세계 티커 및 국내 종목 코드 즉시 입력 가능
     - **디폴트 5종목**: 삼성전자(`005930`), SK하이닉스(`000660`), 마이크론(`MU`), 샌디스크(`SNDK`), TSMC(`TSM`)
   - **조회 기간 선택**:
     - `1M`(디폴트), `3M`, `6M`, `1Y`, `3Y` 선택 지원
   - **"조회" 버튼**:
     - 종목 및 기간 설정 후 클릭 시 즉시 실시간 데이터 취합 및 차트 업데이트
2. **오른쪽 메인 분석 대시보드**:
   - **타이틀 영역**:
     - `"한국 및 미국 시장 종목별 PER 변화 추이 비교"` (색상: `#8AB4F8`, 서브타이틀 생략, 가로선 구분)
   - **핵심 밸류에이션 KPI 메트릭 카드**:
     - 5개 종목의 현재 PER, 기간 평균 PER, 기간 내 변동률(%) 요약 표시
   - **다채로운 차트 탭**:
     - **📊 PER 절대 수치 추이**: 5개 종목의 실제 PER 수치 변동을 고대비 다크 테마 라인 차트로 비교
     - **📈 상대 멀티플 지수 (기준일=100)**: 기준점 대비 밸류에이션 배수 확장/수축(Multiple Expansion/Contraction) 추이 시각화
     - **🎯 밸류에이션 밴드 (Min-Avg-Max)**: 각 종목의 기간 내 최저/평균/최고 PER 및 현재 위치를 가로 레인지 바 형태로 한눈에 비교
   - **데이터 영역 & 엑셀 다운로드**:
     - 기간 요약 통계 테이블 및 일별 시계열 데이터 테이블
     - 📥 **엑셀 다운로드(`.xlsx`)**: 2개 시트(통계 요약, 일별 시계열) 구성의 엑셀 보고서 다운로드 지원
   - **전문가 관점 밸류에이션 인사이트**:
     - 최고/최저 밸류에이션 종목, 멀티플 최대 확장 종목, 데이터 산출 기준 안내

## ⚙️ 데이터 산출 파이프라인

- **한국 주식**: `pykrx`의 공식 KRX 일별 펀더멘털 데이터 수집 (`get_market_fundamental_by_date`), KRX 로그인 자동 연동, 유사시 `yfinance` TTM EPS 폴백.
- **미국 주식**: `yfinance` 일별 종가 데이터와 분기별 공시 순이익(`earnings_dates`의 Reported EPS)의 롤링 4분기 합산(TTM EPS)을 일별로 결합하여 PER = Price / TTM EPS를 연속 시계열로 정밀 계산.
